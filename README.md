# force_snatteri (archived)

> **This resource is no longer maintained and the repository is archived (read-only).**

**What it was:** Shoplifting for FiveM (ESX). Preview: https://www.youtube.com/watch?v=Ee8dr28XP9U

**Why it's archived:** It was a small early script for ESX/Revoked that depends on a private progress bar resource (sjrp_progressbar) and the removed esx:getSharedObject event. It also uses the deprecated `mysql-async` / `esx:getSharedObject` APIs that current ESX Legacy no longer supports.

The code stays available for reference and for anyone who wants to adapt it to their own server, but it gets no updates or support.
